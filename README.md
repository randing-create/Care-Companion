# Care Companion App Skill

我爸受伤后,我人在国外,什么都帮不上。于是我让 Claude 帮我做了一个 App——
营养提醒、康复运动指导、21天冥想课程、连续打卡火焰、经验值升级——
全部装进一个手机网页里,他在微信里点开就能用,不需要任何账号或下载。

这个仓库把"做这个App"的过程，打包成了一个可复用的 **Claude Skill**。
如果你也有家人在异地康复、需要陪伴和提醒，把这个 Skill 装进你的 Claude，
告诉它你家人的具体情况，它会帮你定制一个属于你们的版本。

## 这个Skill能做什么
- 📋 营养 / 用药提醒打卡
- 🏃 康复运动指导(可在床上完成)
- 🧘 嵌入任意外部课程(冥想/语音/视频)
- 🔥 连续打卡streak + 经验值升级系统(像多邻国一样好玩)
- 🏆 成就徽章
- 🎙️ 可选：录一段你的声音，完成打卡时自动播放鼓励

## 怎么用
把 `SKILL.md` 装进你的 Claude，描述你家人的情况，Claude 会基于
`assets/reference-app.html` 这份参考模板帮你定制。部署方式见
`references/deployment-guide.md`(推荐 Replit，零代码经验也能用)。

⚠️ 模板里的营养计划、运动指导、复诊提醒均为示例内容，请根据
家人的实际情况和医生建议调整，不构成医疗建议。
